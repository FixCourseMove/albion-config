## 🧩 About

**Albion Online Config** is a comprehensive configuration tool for Albion Online featuring overlay menu, stat tracker, inventory manager, build loader, and loot logger.

Based on popular mods like **Albion Overlay**, **Albion Helper**, and **Albion Utility**.

---

## ✨ Features

### 🎮 Core Features
- Overlay Menu — in-game menu with hotkey toggle
- Stat Tracker — real-time health, mana, and cooldown display
- Inventory Manager — auto-sort and quick-stack items
- Build Loader — load and save equipment presets
- Loot Logger — track drops and silver gains

### 🎨 Interface & Customization
- Custom HUD — movable widgets and themes
- Minimap Enhancements — resource and enemy markers
- Chat Filters — highlight important messages
- Keybind Manager — rebind actions for convenience

### 🏋️ Utility & Training
- DPS Meter — measure damage output
- Gathering Tracker — log resources collected
- Market Helper — price check integration
- Safe Mode — disable risky features
